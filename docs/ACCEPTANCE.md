# 验收清单

## 自动化全链路验收

运行 `python -m pytest backend/core/tests/test_workflow.py -q`，验证从三平台模拟订单到分仓预占、出库追踪、退货退款、补货采购、成本分摊入库和平台结算的九步闭环。前端可在“全链路沙盘”点击“一键跑通全流程”，九个节点全部点亮即表示当前演示账套闭环成功。

- [ ] 三个平台模拟连接测试成功，重复同步不产生重复订单。
- [ ] SKU 映射后订单分仓生成预占，重复分仓不重复预占。
- [ ] 发货单过账扣减现有量与预占量，并创建追踪回传任务。
- [ ] 采购收货按选择的分摊方式生成到岸成本与库存流水。
- [ ] 调拨发出增加目标仓在途量，收货后转为现有量。
- [ ] 退货质检按良品、残次和报废处理库存并更新退货数量。
- [ ] 补货建议显示计算输入，审批后可转为采购单。
- [ ] 原币、汇率、本位币金额和订单贡献利润计算正确。
- [ ] 各岗位写权限受到限制，敏感动作可在审计日志追踪。
- [ ] Excel 预览、成功行导入、错误行报告和幂等重试正确。
- [ ] API Key 库存回传幂等，Webhook HMAC 签名可验证。
- [ ] 数据库备份可在全新环境恢复。
