# NEXUS Commerce OS 使用手册

## 全链路沙盘（无真实平台凭证时）

登录后进入左侧“全链路沙盘”。可以逐步执行九个业务节点，也可以点击“一键跑通全流程”。每次执行都会写入当前演示账套：

1. 准备商品、供应商、三平台店铺、双仓与期初库存。
2. 模拟同步 Amazon、Wayfair、Walmart 新订单。
3. 自动分仓并预占库存。
4. 生成出库单与追踪号，扣减库存并模拟回传。
5. 创建退货、完成质检、良品入库与退款。
6. 计算可解释的补货建议。
7. 审批建议并生成采购单。
8. 模拟到货，按体积分摊头程成本并入库。
9. 生成平台结算单并归集订单贡献利润。

平台数据是模拟的，订单、库存、采购、财务和审计记录均使用正式领域模型。沙盘不会删除已有数据，可以反复运行生成新的订单波次。

## 首次进入

运行 `scripts\init.ps1` 后访问 `http://本机IP:8080`。演示账号为 `admin / Admin123!`，首次进入后应在系统管理中创建个人管理员账号并停用演示密码。

初始化顺序：

1. 在“商品中心”维护供应商、SPU、SKU、包装尺寸、采购交期和安全库存。
2. 在“仓储库存”维护实际仓库与履约节点，并通过期初库存模板导入库存。
3. 在“平台连接”配置平台账号，再建立账号下的店铺和渠道 SKU 映射。
4. 使用沙箱/本地模拟器完成订单同步、分仓和库存预占测试。
5. 验证生产凭证权限后，关闭“使用本地模拟器”并切换为生产环境。

## 日常订单流程

1. 平台连接器每五分钟增量同步订单，也可在“平台连接”手工同步。
2. 新订单进入“待确认”。渠道 SKU 未映射时保留订单，但不会自动占用库存。
3. 点击“分仓”，系统按仓库优先级与可用量创建库存预占。库存不足的订单进入“缺货”。
4. 仓库创建发货单、包裹及包裹商品，过账后系统扣减现有量与预占量。
5. 发货过账不因平台网络错误回滚；追踪号回传由后台任务重试，并在同步任务中显示失败原因。

## 采购、收货与补货

- 补货中心根据销量、采购/生产/海运提前期、安全库存、在途量、MOQ 和整箱数生成建议。
- 建议必须由采购角色审批，随后转成采购单；系统不会自动向供应商下单。
- 采购单按“草稿 → 待审批 → 已下单 → 生产中 → 在途 → 部分收货/完成”推进。
- 收货单过账时按数量、重量、体积或货值分摊头程与关税，并更新移动平均成本。

## 退货与经营财务

- 退货质检可选择良品入库、残次品隔离或报废。每次库存变化都会生成不可修改的库存流水。
- 财务流水保留原币、汇率和人民币本位币金额。收入为正数，各类成本和退款也以正数录入，利润报表会按费用类型扣减。
- 系统用于经营核算，不代替法定会计总账、税务申报或 VAT 申报。

## Excel 导入

在“数据导入”选择业务类型后下载标准模板。上传文件后先预览，再确认执行。系统按业务编码更新或创建记录，每行独立校验；错误行会保留原始数据与原因，成功行不受影响。

## 权限

- 管理员：全部权限与平台密钥/API Key 管理。
- 运营：商品、订单、渠道映射和同步操作。
- 采购：供应商、采购单、补货审批。
- 仓库：分仓、库存、发货、收货、盘点和调拨。
- 财务：费用、汇率、结算与利润。
- 管理层：只读查看和报表。
